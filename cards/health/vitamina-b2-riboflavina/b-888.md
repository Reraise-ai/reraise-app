> For adults, the AR and PRI are set at 1.3 and 1.6 mg/day. … No tolerable upper intake level has been set for riboflavin.

Quoted from EFSA, Scientific Opinion on Dietary Reference Values for riboflavin (EFSA Journal 2017), S. 10–27 (Adults), S. 108–113 (UL conclusion).

- context: Dietary Reference Values for the European population; PRI = Population Reference Intake
- upperLimit: No UL set (no sufficient data on adverse effects)
- bloodTarget: EGRAC ≤ 1.3 (erythrocyte glutathione reductase activation coefficient) as biomarker
- perDay: 1,6 mg/day (adults, PRI); 1,9 mg (pregnant); 2,0 mg (breastfeeding)
