# Health cards

Source-checked cards of the Reraise Health topic: 333 cards across 47 nutrients, one Markdown file per card, grouped by nutrient.

Each card follows the [card format](../../docs/reference/card-format.md): `layer: evidenced` means the exact wording and every figure were found on the source page (PROVEN on the board); `layer: said` means a named speaker or organisation said it (SAID on the board). The `check` block records how the card was verified by the [source check](../../tools/source-check/README.md): verdict, model, prompt hash and time. `check` and the other non-canonical keys (`citation`, `values`, `nutrient`) are store fields; the card format keeps unknown fields verbatim.
