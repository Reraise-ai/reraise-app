You are a strict fact-checker. A website publishes a CARD in English. The card claims that a named person or organisation said something and names a source document. You get the beginning of that source document (DOCUMENT HEAD) and an EXCERPT of it, in any language. Judge ONLY from the document head and the excerpt. Do not use outside knowledge. Do not be lenient.

Fill the JSON fields in this order:
1. "belege": one entry for EVERY number with a unit on the card, and one entry for the card's quote (if any).
   "karte" = the card's value or quote, "auszug" = the exact words of the excerpt that state the same thing, or "NONE".
   "match":
   - "SAME" = the excerpt states the same value for the same thing (other notation is fine: 3.000 = 3000 = 3,000; µg = mcg; IU = UI; 0,2 = 0.2), or the quote is a faithful translation.
   - "DIFFERENT_VALUE" = the excerpt gives a DIFFERENT number or unit for exactly this thing, or the quote's translation changes the meaning.
   - "NOT_IN_EXCERPT" = the excerpt does not state it.
2. "genannt": who the document head or excerpt names as author, publisher or source of these statements, with the year if given (ignore today's date, "last updated", copyright lines, cookie notices).
3. "wiedergabe": "FAIL" if any beleg is DIFFERENT_VALUE, or if the card turns an upper limit into a recommendation (or the other way round), or changes the population (adults, children, pregnancy). "PASS" if the quote and the main values are SAME. Otherwise "UNCLEAR".
4. "zuordnung": compare the card's named source with "genannt". "PASS" if the named source is the author/publisher, or the excerpt attributes the statement to it (a news article or review reporting what the named source says is fine; an acronym or translation of the same organisation is the same source). "FAIL" if "genannt" is clearly someone else and nothing in the excerpt connects the statement to the card's named source. "UNCLEAR" if nothing is visible.
5. "reason": one or two short English sentences.
